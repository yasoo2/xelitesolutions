Create a simple Node.js CLI tool named csvcol that prints one named column from a CSV file to stdout, one value per line in file order. The tool takes the CSV file path as its first argument and the column name as its second argument, plus an optional --delimiter D flag (a single character used to split fields; default is a comma). The first line of the file is the header row; match the column name exactly against the header fields. Strip a trailing carriage return from each line. If a data row has fewer fields than the header, print an empty line for that row. If the file does not exist, print a message starting with "file not found" to stderr and exit with code 3. If the named column is not in the header, print a message starting with "column not found" to stderr and exit with code 3. If the file or column arguments are missing, or --delimiter is missing its value or its value is not exactly one character, print a message starting with "invalid arguments" to stderr and exit with code 2. Include a sample CSV file with at least three columns and five data rows and an npm test script that verifies column extraction, row order, the delimiter flag, short-row behavior, and the error cases.
