Build a Node.js command-line tool named inisection. Given a section name and an INI-style file path, running `node inisection.js <section> <file>` prints each key=value line under that [section], one per line, in file order, skipping blank lines and lines starting with ; or #. If the file does not exist, exit with code 3 and print a one-line error starting with the words file not found. If the section name is missing or empty, exit with code 2 and print a one-line usage error. Include a sample INI file with at least 3 sections and 12 non-empty lines. Add an `npm test` script that verifies the section extraction for the sample file, the missing-file behavior, and the missing-section behavior. Run the tests yourself and only finish when they pass on this machine.
