Build a Node.js command-line tool named jsonkeys. Given a JSON file path, running `node jsonkeys.js <file>` prints the top-level key names of the JSON object, one per line, sorted alphabetically. With a `--count` flag instead of listing, it prints only the number of top-level keys. If the file does not exist, exit with code 3 and print a one-line error starting with the words file not found. If the file is not valid JSON, exit with code 2 and print a one-line error starting with the words invalid json. Include a sample JSON file with at least 6 top-level keys, including nested objects and arrays as values. Add an `npm test` script that verifies the key listing for the sample file, the --count behavior, the missing-file behavior, and the invalid-json behavior. Run the tests yourself and only finish when they pass on this machine.
