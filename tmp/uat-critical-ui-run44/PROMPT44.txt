Create a simple Node.js CLI tool named wordwrap that wraps the lines of a text file to a maximum width and prints the result to stdout. The tool takes the file path as its first argument and an optional --width W flag (a positive integer; default 40). Each non-empty input line is one paragraph: reflow its words so no output line exceeds W characters, breaking only on spaces; a word longer than W is split hard at W characters. Empty input lines are preserved as empty output lines (paragraph separators). Strip a trailing carriage return from each input line. If the file does not exist, print a message starting with "file not found" to stderr and exit with code 3. If the file argument is missing, or --width is missing its value or its value is not a positive integer, print a message starting with "invalid arguments" to stderr and exit with code 2. Include a sample text file with multiple paragraphs including an overlong word and an npm test script that verifies wrapping, the width flag, blank-line preservation, overlong-word splitting, and the error cases.
