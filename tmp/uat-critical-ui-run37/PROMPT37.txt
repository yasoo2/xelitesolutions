Build a Node.js command-line tool named loggrep that reads a log file given as its first argument, line by line. It prints only the lines containing the word ERROR or the word WARN (case-sensitive), preserving their original order and content exactly. It also supports a flag mode: running `node loggrep.js --count <logfile>` prints only the number of matching lines. If the file does not exist, exit with code 3 and print a one-line error starting with the words file not found. If no argument is given, exit with code 2 and print a one-line usage message starting with the word usage. Include a sample log file with at least 12 lines including some ERROR lines, some WARN lines, and some lines with neither. Add an `npm test` script that verifies the filtered output for the sample file, the --count mode, the missing-file behavior, and the missing-argument behavior. Run the tests yourself and only finish when they pass on this machine.
