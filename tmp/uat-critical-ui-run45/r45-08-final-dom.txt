What's the idea this evening?

Create a simple Node.js CLI tool named palin that reads a plain text file containing one phrase per line and prints one line per phrase to stdout in the format "PHRASE -> yes" or "PHRASE -> no", where PHRASE is the original phrase exactly as written and yes/no says whether the phrase reads the same forwards and backwards. By default the comparison is exact (case-sensitive, spaces and punctuation significant). The tool accepts the file path as the first argument plus optional flags --ignore-case (compare case-insensitively), --ignore-spaces (remove all whitespace before comparing), --yes-only (print only palindromes), and --no-only (print only non-palindromes). The --ignore-case and --ignore-spaces flags may be combined with each other and with either output filter. Passing both --yes-only and --no-only together is an error. Preserve input order. Skip blank lines silently. If no phrases qualify for printing, print nothing to stdout and exit 0. If the file does not exist, print a message starting with "file not found" to stderr and exit with code 3. If the arguments are invalid (unknown flag, both output filters together, or missing file path), print a message starting with "invalid arguments" to stderr and exit with code 2. Include a sample phrases file with at least 12 lines covering clear palindromes and non-palindromes plus at least one blank line and at least two tricky lines that change verdict under --ignore-case or --ignore-spaces, and an npm test script that verifies comparison, the flags, and the error cases.
