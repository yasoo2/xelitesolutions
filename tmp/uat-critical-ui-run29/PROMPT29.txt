Build a small Node.js command-line tool named wordtally that reads a text file given as its first argument and prints the 5 most frequent words (case-insensitive, one per line as `word: count`), skipping words shorter than 3 letters. If no file argument is given, print a one-line usage message and exit with code 2. If the file does not exist, exit with code 3 and print a one-line error starting with the words cannot open. Include a sample text file with at least 30 words. Add an `npm test` script that verifies the top-5 output for the sample file, the usage/exit-2 behavior, and the missing-file behavior. Run the tests yourself and only finish when they pass on this machine.
