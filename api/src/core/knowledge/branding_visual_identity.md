# Branding & Visual Identity: The Digital Soul

## 1. Brand Alignment
- **Mission-to-Visual**: If the brand is "Trustworthy" (Banking), use Indigo/Navy Blues. If "Dynamic" (AI/Startup), use Neons/Gradients.
- **The Voice**: Ensure the system's tone (Copywriting) matches the design. Modern UI needs concise, friendly, active language.

## 2. Logo & Iconography
- **SVG Mastery**: Logos must be mathematical SVGs for infinite scaling.
- **Icon Set Consistency**: Never mix icon sets (e.g., FontAwesome with Lucide). Stick to one stroke width (usually `1.5px` or `2px`).
- **Logo Safe Zones**: Maintain a clearance of 50% of the logo's width around it to prevent visual clutter.

## 3. Multi-Theme Visual Identity
- **Cyber-System (Dark)**: Deep charcoals (`#121212`) over pure black (`#000000`). Neon accents for "Active" states.
- **Enterprise (Light)**: Clean whitespace, high-contrast text (`#1a1a1a`), and sophisticated borders (`1px solid #e2e8f0`).
- **Semantic Tokens**: Define colors by purpose (`--color-surface`, `--color-brand`) rather than literal names (`--color-blue`).

## 4. Accessibility (WCAG 2.1)
- **Contrast**: Ensure text-to-background ratio is at least `4.5:1` for normal text and `3:1` for UI elements.
- **Focus Order**: Interactive elements must be navigable via Keyboard in a logical order (Top-Down, Left-Right).
- **Alt Text**: Every visual cue must have a descriptive text alternative for screen readers.
