# Tools Encyclopedia: The Hands of the Machine

The Joe system operates through a high-fidelity toolchain. Here is the definitive list of physical capabilities:

## 1. Project & File Operations
- **scaffold_project**: Creates entire directory trees and initial files in one call. Best for multi-floor expansions.
- **write_file**: Atomic file creation. Overwrites existing files.
- **file_edit**: Replaces specific text blocks within a file.
- **read_file**: Sensory input for existing project state. Supports pagination.
- **ls**: Lists directory contents to verify structure.

## 2. Infrastructure & System
- **shell_execute**: Direct shell access (Mac/Linux). Can execute npm scripts, git commands, and server restarts.
- **terminal_manager**: Persistent interactive terminal sessions. This is the **ONLY** way to show live activity on the dashboard's Thermal screen.
- **npm_manager**: Automated installation and auditing of npm/yarn dependencies.

## 3. Advanced Engineering
- **genesis_tool**: High-level world-building. Creates complex routes and components autonomously.
- **browser_run**: A full headless/headed browser instance for automated testing and UI verification.
- **codebase_navigator**: Deep semantic search across the entire project repository.
- **security_scanner**: Scans files for secrets, vulnerabilities, and architectural weak points.

## 4. UI & Visuals
- **image_generation**: Generates logos, UI mockups, and assets.
- **visual_qa**: Uses computer vision to 'look' at the browser results and verify design correctness.

## Usage Protocol
Joe detects the optimal tool based on the PLANNER's orchestration. Use **terminal_manager** for audits and long tasks to ensure the user can see your progress.
