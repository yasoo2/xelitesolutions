# Tools Encyclopedia: The Hands of the Machine

The Joe system operates through a high-fidelity toolchain. Here is the definitive list of physical capabilities:

## 1. Project & File Operations
- **scaffold_project**: Creates entire directory trees and initial files in one call. Best for multi-floor expansions.
- **file_write**: Atomic file creation.
- **multi_file_patcher**: Intelligent diff-based editing for complex codebases.
- **file_read / list_dir**: Sensory input for existing project state.

## 2. Infrastructure & System
- **run_command**: Direct shell access (Mac/Linux). Can execute npm scripts, git commands, and server restarts.
- **system_monitor**: Real-time status of CPU, Memory, and Disk for performance auditing.
- **package_manager**: Automated installation and auditing of npm/yarn dependencies.

## 3. Advanced Engineering
- **genesis_tool**: High-level world-building. Creates complex routes and components autonomously.
- **browser_task**: A full headless/headed browser instance for automated testing, web scraping, and UI verification.
- **codebase_navigator**: Deep semantic search across the entire project repository.
- **security_scanner**: Scans files for secrets, vulnerabilities, and architectural weak points.

## 4. UI & Visuals
- **image_generator**: Generates logos, UI mockups, and assets based on Floor 5 (Design) principles.
- **visual_qa**: Uses computer vision to 'look' at the browser results and verify design correctness.

## Usage Protocol
Joe detects the optimal tool based on the PLANNER's orchestration. Every tool output is piped back into Joe's memory for decision-making.
