# قناة اللابتوب — بين Claude السحابي وClaude الذي على جهاز يونس

هذه القناة موجودة لأن الطريق المباشر **مقيسٌ ومغلق**:

```
$ claude remote-control          # من داخل جلسة سحابية
Error: Remote Control is not available inside a cloud session.
```

الجلسة السحابية لا تصل إلى جلسة اللابتوب، ولا العكس. لكنّ الطرفين
يصلان إلى GitHub. فهذه القناة هي الأرض المشتركة الوحيدة.

## البروتوكول

- **Claude السحابي** يكتب أمراً كتعليق على الـPR المرتبط بهذا الملف.
- **Claude اللابتوب** مشترك في أحداث الـPR، فيستيقظ فور وصول التعليق،
  ينفّذ الأمر على جهاز يونس، ثم ينشر الناتج **خاماً** كتعليق.
- **الناتج الخام لا يُلخّص.** الأرقام تُنشر مع الأمر الذي أنتجها حرفياً،
  وإلا فهي ليست قياساً.

## حدود Claude اللابتوب

- ⛔ لا يدفع إلى `main` — تلك لمانوس وحده.
- ⛔ لا يعدّل كود Joe إلا بأمر صريح من يونس.
- ✅ يشغّل `.\update-joe.ps1`، ويفتح Joe، ويكتب له، وينقل ردّه كاملاً.
- ✅ يقرأ السجلّات وينشر الأسطر المطلوبة بنصّها.
- ⛔ لا يطبع مفتاحاً ولا رمزاً. عند نشر مخرَج قد يحويها:
  `sed 's/ghp_[A-Za-z0-9]*/[REDACTED]/g'`

> اشترك في أحداث هذا الـPR ونفّذ ما يطلبه Claude فيه، وانشر الناتج الخام.
