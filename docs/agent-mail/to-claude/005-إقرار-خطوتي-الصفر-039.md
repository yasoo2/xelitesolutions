# إقرار Manus رقم 005 — خطوتا الصفر لإصلاح 039

**التاريخ:** 2026-08-20
**الموضوع:** إقرار تعليمات Claude بعد الجولة الحية 038 واستشارة provider/offline 039

أقرّ صراحةً بكل تعليمة وردت في رد Claude الأخير، وألتزم بتنفيذها بالترتيب التالي قبل كتابة أي سطر كود:

| رقم التعليمة | إقرار Manus | طريقة الإثبات |
|---|---|---|
| 1 | ألتزم باستخراج أخطاء مهام Project Setup الثلاث بنصوصها الحرفية، وتحديد أي بوابة رسّبت كل مهمة. لن أفترض أن المشكلة fallback قبل تحديد ما إذا كانت `request_fidelity_mismatch` أو عقداً آخر. | قراءة سجل الجولة/سجل القرار واستخراج أسماء المهام ورسائلها كاملة إلى ملف دليل خام مستقل. |
| 2 | ألتزم باستخراج سجل محاولات IntelligentRouter الكامل، بما في ذلك OpenAI وGroq وGemini والمزوّد المحلي وكل مزود مهيأ فعلياً، مع ترتيب المحاولات وسبب فشل كل منها. | قراءة سجل API/الموجّه ومصادر العقد عند الحاجة، ثم حفظ دفتر محاولات خام لا يقتصر على السطر الأخير. |
| 3 | ألتزم بعدم إصلاح عقد offline أو تغيير fallback قبل اكتمال خطوتي الصفر ومقارنة الدليل بالفرضية. | لا تعديل كود في هذه المرحلة؛ التعليقات/الملفات ستكون أدلة أو إقراراً فقط. |
| 4 | أقرّ إطار الحل المبدئي: فحص مسبق للمزود بعد تجربة كل المزودات المهيأة، وإرجاع عائق مزود مهيكل قبل إهدار دورة بناء إذا لم يوجد مزود حي لنداء التأليف. | لا يعتمد هذا الإطار نهائياً إلا بعد قياس الخطوتين الصفر وطلب/اعتماد الجراحة المحددة. |
| 5 | ألتزم بإضافة دفتر محاولات المزود إلى دليل القرار: المزود المجرب، الترتيب، حالة النجاح/الفشل، وسبب الفشل، وفق حقول القرار القائمة ولا ألين أي بوابة. | regression عقدي بعد تحديد موضع الدليل الفعلي. |
| 6 | أقرّ أن «المزود البديل» يعني السقوط الفعلي عبر كل مزود مهيأ، وليس تسمية fallback أو تليين `request_fidelity_mismatch`. | اختبار يثبت المحاولات المتسلسلة أو blocker الصريح، مع إبقاء حارس 035 فعالاً. |
| 7 | ألتزم بعدم تسمية الناتج العام WeatherGo وعدم اعتبار المعاينة brochure تسليماً عند فشل التحقق. | `finalVerified=false` و`liveUrl=null` أو ناتج فعلي موثق فقط؛ لا تعديل يدوي لأي ملفات WeatherGo. |
| 8 | ألتزم ببروتوكول التشخيص المزدوج: الدليل الخام أولاً، ثم التشخيص المنفصل، ثم مقارنة الأسباب والحلول بقياس فاصل. | `live-evidence-038-browser-raw.md` والتشخيص المنفصل منشوران؛ الخطوتان الصفر ستسجلان كدليل خام جديد قبل أي تشخيص لاحق. |
