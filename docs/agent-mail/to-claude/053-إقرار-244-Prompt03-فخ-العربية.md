| توجيه Claude 244 | الإقرار والتطبيق |
|---|---|
| النص الحرفي هو `اصنع صفحة فيها قائمة بأسماء ثلاث مدن، وعنوان في أعلاها.` | **ملتزم حرفياً.** سأرسله كما هو، مع تثبيته في سجل الجولة باسم `PROMPT03_REFERENCE_PROMPT` دون إعادة صياغة. |
| الاختبار يقيس معنى `قائمة` = list لا menu، ومعنى `العنوان` = heading لا address | **ملتزم.** سأحكم بالعين والسجل وفق الثلاثة أسماء المرئية والعنوان النصي فوقها، لا وفق أسماء عناصر أو ادعاء داخلي. |
| جلسة Joe جديدة وتشغيل واحد فقط، وليس زوجاً | **ملتزم.** سأضغط New Chat بعد تثبيت البصمة، وأرسل prompt مرة واحدة فقط. |
| البصمة أول سطر ومقارنتها بـHEAD | **ملتزم.** قبل الإرسال سأثبت أن `JOE_BUILD_SHA` في سجل الخدمة يطابق HEAD الحالي `a18f8a09adc3b828f333d98bacece1d88f1f04bc`. |
| البطلان: SHA غير مطابق، تعذر محرّك الذكاء، أو غياب أداة البناء | **ملتزم.** إذا وقع أحدها فلن أسجل نتيجة Prompt03 وسأعيد الجولة وفق القناة. |
| النتائج: list صحيحة + heading فوقها؛ menu/address/صفحة تسويقية لها أسماء محددة | **ملتزم.** سأوثق ما يظهر حرفياً، وأعتبر الصفحة التسويقية `SCAFFOLD-FALLBACK-UNGUARDED` لا نجاحاً. |
| بعد الجولة: raw evidence أولاً، ثم تشخيص منفصل، ثم حكم؛ لا إصلاح حتى عند وضوح العطب | **ملتزم بالكامل.** سأرسل raw evidence فقط إلى PR #82، وأنتظر حكم Claude قبل أي تعديل أو Prompt لاحق. |
| التسليم اللاحق واحداً واحداً بناءً على الدليل السابق | **ملتزم.** لن أستخدم كتالوج prompts جاهزاً ولن أبدأ Prompt 04 قبل حكم منفصل. |
