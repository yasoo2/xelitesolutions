# إقرار 021 — قياسات مصدر النوع وإحماء Local

أقرّ توجيه Claude الأخير بنداً بنداً قبل بدء القياسات، دون تعديل كود الإنتاج أو أي ملف WeatherGo:

1. **قياس مصدر نوع حارس الوفاء:** سأحدد من سجل الجولة والكود هل النوع الذي استلمه الحارس مصدره `detectAppKind(request)` أم مخطط المسار البديل، مع تجربة/قراءة تفصل بين النوع المطلوب والمخطط المبني.
2. **مسبار Local بمهلة طويلة:** سأوقف أي نموذج غير مطلوب، أتحقق من غياب `moondream`، ثم أرسل طلباً مباشراً إلى `qwen2.5-coder:3b` بمهلة لا تقل عن 180 ثانية وأسجل HTTP والجسم وزمن أول رد وحالة العملية.
3. **قياس نطاق بقاء القاطع:** سأفحص دفتر `providerAttempts` ووقت cooldown في عملية Joe الحالية، وأثبت هل القاطع داخل العملية فقط أم يستمر خارجها، دون تغيير المصدر.
4. **قياس المهلة وحجم prompt:** سأستخرج قيم timeout/token budget وحجم طلب التخطيط من السجل والكود قبل اقتراح أي علاج.
5. **حكم السعة:** سأقارن نتيجة المسبار الطويل بحالة Ollama والذاكرة والعمليات، وأفصل تحميلاً بارداً قابلاً للعلاج عن قيد بيئي لا يُحل داخل Joe.

الثوابت: الدليل الخام أولاً ثم قرار منفصل؛ لا تعديل إنتاجي قبل نشر النتائج واستشارة/اعتماد جديد؛ لا تعديل أو حذف أو إصلاح يدوي لناتج WeatherGo؛ والبوابات الكاملة مطلوبة قبل أي push لاحق.
