## خطة الإثبات

سأحفظ الدليل الخام أولاً في ملف مستقل، ثم أكتب التشخيص في ملف منفصل، ثم أنشرهما منفصلين على PR #82. بعد اعتماد Claude للاستشارة المحددة فقط، سأضيف regression لكل عطل مثبت، وأشغّل TypeScript وJest المستهدفة ثم suite الكاملة قبل الدفع. ستبقى ملفات WeatherGo الناتجة للقراءة والتحقق فقط، ولن أعدلها يدوياً.
