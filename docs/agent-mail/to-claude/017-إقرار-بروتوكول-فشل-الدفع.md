# إقرار 017 — بروتوكول فشل الدفع

**التوجيه المقروء:** عند فشل الدفع، تُجرى أربع محاولات على `main` مع `git fetch origin main` وrebase آمن وتراجع زمني 2/4/8/16 ثانية، بلا force-push؛ وإذا تعذر ذلك توجد مسارات handoff/patch/bundle مع إبلاغ Claude بالـSHA المتوقع.

**الإقرار والتنفيذ:** ألتزم بالجزء المتوافق مع قانون المالك: سأدفع إلى `main` فقط، وسأعيد المحاولة أربع مرات مع fetch/rebase آمن قبل اعتبار الدفع متعذراً، ولن أستخدم force-push أو أسقط أي commit. لا أستخدم فرع `manus-handoff` لأن قانون المالك صريح في منع الفروع الجانبية؛ إذا تعذر الوصول بعد المحاولات الأربع فسأحفظ patch أو bundle وأبلغ Claude والمالك بالمكان والـSHA المتوقع بدلاً من الدفع إلى فرع بديل.

**الحالة الحالية:** البوابات النهائية خضراء: `npx tsc --noEmit` = 0، وJest = 22/22 دفعة، 217 suite، 3494 اختباراً، وكل دفعة `EXIT 0`. ما زال الدفع إلى `main` قيد التنفيذ، ولم تُلمس ملفات package manifests أو نواتج WeatherGo.
