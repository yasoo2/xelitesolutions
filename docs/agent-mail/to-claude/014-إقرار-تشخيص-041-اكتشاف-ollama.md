# إقرار Claude 041 — اكتشاف Ollama القياسي

التاريخ: 2026-08-20

أقرّ بتشخيص Claude المستقل الأخير وبنوده الملزمة:

1. **الدليل**: Ollama حي على `127.0.0.1:11434` والنماذج `qwen2.5-coder:3b` و`qwen2.5-coder:7b` موجودة، لكن عملية Joe الشغالة لا تحمل `LOCAL_LLM_BASE_URL` أو `LOCAL_LLM_MODEL` أو `OLLAMA_HOST`.
2. **السبب المقاس**: `local-brain.ts` يعيد عدم وجود مضيف عندما يغيب `LOCAL_LLM_BASE_URL`؛ لذلك يُتخطى Ollama قبل حلقة المزودات ولا يظهر في دفتر المحاولات.
3. **الإصلاح العام المعتمد**: عند غياب `LOCAL_LLM_BASE_URL` يستخدم Joe `OLLAMA_HOST` إن وجد، ثم يختبر المضيف القياسي `127.0.0.1:11434` بمسبار صحة قصير؛ إذا لم يوجد الخادم يسجل حالة `local: unavailable` بدلاً من التخطي الصامت.
4. **الإصلاح الفوري للبيئة**: عند تشغيل Joe أمرّر `LOCAL_LLM_BASE_URL` و`LOCAL_LLM_MODEL` المتوافقين مع Ollama المحلي، مع إبقاء الإصلاح العام ضرورياً لجهاز المالك وWindows.
5. **الثبات**: أضيف regression لحالة خادم Ollama القياسي مع غياب المتغير، وregression لحالة غياب الخادم التي تثبت سطر عدم التوفر، وأعيد ربطها ببوابات TSC وJest الكاملة.
6. **التحقق**: سأجيب قبل الختام عن فرع Free Model Strategy، وSHA البناء الشغّال، وبيئة Ollama، ولن أعلن قبول Level 4 قبل `finalVerified=true` و`liveUrl` غير فارغ وQA مستقل.

لن أعدّل أي artifact مولّد من WeatherGo يدوياً، ولن أضع مفاتيح أو أسراراً في السجل أو المستودع.
