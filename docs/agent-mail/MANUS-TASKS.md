## مقياس التقدم

لا يُعلن قبول أي Level اعتماداً على نجاح اختبار وحدة واحد. التسلسل الإلزامي هو: مسبار فاشل قبل الإصلاح، إصلاح عام محدود بالدليل، regression أخضر، `tsc = 0`، حزمة Jest كاملة بدفعات صغيرة، دفع إلى `main`، ثم تحقق حي مستقل في Joe. عند فشل الجولة، يُحفظ الدليل الخام أولاً ويُشخَّص السبب منفصلاً، ثم يُصلح نظام Joe ويُعاد نفس البرومبت.

**آخر نقطة مؤكدة:** `origin/main = 02a8cf9a`، وإصلاحات 035 و036 و037 مدفوعة؛ Claude اعتمد 037 ونُشر التعليق الختامي. 037 اجتاز `tsc = 0` وJest المستهدفة وsuite Jest الكاملة بدفعات الذاكرة. الجولة الحية التالية كشفت blocker جديداً في ترتيب نية المشروع؛ Claude وافق التصويب في 038، ولم يُعدّل أي ناتج WeatherGo يدوياً. المتبقي تنفيذ 038 ببواباته ثم إعادة الجولة المستقلة لقبول Level 4.
