## مقياس التقدم

لا يُعلن قبول أي Level اعتماداً على نجاح اختبار وحدة واحد. التسلسل الإلزامي هو: مسبار فاشل قبل الإصلاح، إصلاح عام محدود بالدليل، regression أخضر، `tsc = 0`، حزمة Jest كاملة بدفعات صغيرة، دفع إلى `main`، ثم تحقق حي مستقل في Joe. عند فشل الجولة، يُحفظ الدليل الخام أولاً ويُشخَّص السبب منفصلاً، ثم يُصلح نظام Joe ويُعاد نفس البرومبت.

**آخر نقطة مؤكدة:** `origin/main = 4acb3d96`، وإصلاحات 035 و036 و037 و038 مدفوعة؛ Claude اعتمد تشخيص 039 المضاد وألزم بإدخال Gemini أو تسجيل دينه. القياس أثبت أن CSS 004 موجود أصلاً في `ProjectRunTool.ts` مع regression حساس لحالة الأحرف، لذلك لم يُكرر. أضيفت regressions A1/A2 بجوار عقد fidelity، وأضيف في `IntelligentRouter` سجل `providerAttempts` وإعادة حجز Local/Ollama قبل keyless/Offline مع Gemini الصريح في mesh. البوابات قبل الدفع خضراء: TSC = 0؛ المجموعة المستهدفة = 11 suites/329 tests؛ Jest الكاملة = 22 دفعة، 217 suites، 3494 tests، وكل دفعة `EXIT 0`. الجولة الحية السابقة توقفت عند `Project Setup (0/3)` بسبب `Insufficient credits` ثم Offline؛ لا تعديل يدوي لناتج WeatherGo، ولا يُعلن Level 4 مقبولاً قبل إعادة الجولة والتحقق المستقل.
