## مقياس التقدم

لا يُعلن قبول أي Level اعتماداً على نجاح اختبار وحدة واحد. التسلسل الإلزامي هو: مسبار فاشل قبل الإصلاح، إصلاح عام محدود بالدليل، regression أخضر، `tsc = 0`، حزمة Jest كاملة بدفعات صغيرة، دفع إلى `main`، ثم تحقق حي مستقل في Joe. عند فشل الجولة، يُحفظ الدليل الخام أولاً ويُشخَّص السبب منفصلاً، ثم يُصلح نظام Joe ويُعاد نفس البرومبت.

**آخر نقطة مؤكدة:** `origin/main = 30f55b67`، وإصلاحات 035 و036 و037 و038 و039 و040 و041 و042 و042b و043 مدفوعة.  042b أصلح حارس اختبارياً فقط بعد أن أثبت full Jest فشل assertion حقيقياً في نافذة 400 حرفاً؛ focused 042b أخضر، ثم أعيدت البوابات النهائية بنجاح: TSC=0 وJest 22/22 و217 suite و3494 اختباراً. لا يزال L4 مفتوحاً حتى جولة Joe الحية والتحقق المستقل بعد إخلاء `moondream`. Claude اعتمد إصلاح acceptance-only بشروطه الثلاثة، وألزم بحسم فرع Free Model Strategy وSHA وبيئة Ollama؛ سُجلت الإقرارات في `to-claude/012` إلى `014`. CSS 004 موجود أصلاً في `ProjectRunTool.ts` مع regression حساس لحالة الأحرف، لذلك لم يُكرر. أضيفت regressions A1/A2، و`providerAttempts`، وGemini/Local-Ollama، و`acceptance_fix`، واكتشاف Ollama القياسي. البوابات الحالية الخضراء: TSC = 0؛ آخر مجموعة 041 = 4 suites/104 tests؛ Jest الكاملة = 22 دفعة، 217 suite، 3494 اختباراً، وكل دفعة `EXIT 0`. Ollama في صندوق القبول يعمل على `127.0.0.1:11434` مع نموذجي `qwen2.5-coder:3b` و`qwen2.5-coder:7b`؛ يجب إعادة بناء Joe بمتغيرات محلية صريحة للجولة. الجولة الحية السابقة توقفت عند `Project Setup (0/3)` بسبب acceptance gap وغياب Local env؛ لا تعديل يدوي لناتج WeatherGo، ولا يُعلن Level 4 مقبولاً قبل جولة جديدة تحقق `finalVerified=true` و`liveUrl` وQA مستقل.
