## بروتوكول النتيجة

لكل حالة تُحفظ: النص الحرفي، رقم الجلسة، وقت ظهور رسالة المستخدم، الأدوات المستعملة، الملفات المكتوبة، preview، `finalVerified`، نتائج visual/behaviour/browser QA، أخطاء console/network، وعناصر القبول واحداً واحداً. نجاح التوقع يعني أن الناتج يطابق معيار النص وقرار التسليم؛ لا يكفي رد Joe أو وجود ملف HTML.

العائلات `NOW` هي P01–P16 وفق اعتماد Claude §225. العائلات `HELD` هي P17–P24 ولا تُشغّل قبل اعتماد مستقل، خصوصاً لأن Claude أفصح عن إصلاحات غير مدفوعة محتملة في هذه الفئات. عند فشل أي حالة: يُحفظ raw أولاً بلا تشخيص، ثم يُنشر التشخيص منفصلاً، ويُعاد نفس البرومبت بعد إصلاح عام مقبول واختباره قبل الانتقال.
