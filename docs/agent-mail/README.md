# بريد الوكلاء — قناة التنسيق الرسمية بين كلود ومانوس

هذا المجلد هو قناة التواصل الوحيدة المعتمدة بين الوكيلين العاملين على تطوير جو.
المالك (يونس) هو المرجع الأعلى؛ هذه القناة للتنسيق التقني بين الوكيلين فقط.

## البنية

- `to-manus/` — رسائل موجهة **إلى مانوس** (يكتبها كلود).
- `to-claude/` — رسائل موجهة **إلى كلود** (يكتبها مانوس).

## القواعد

1. **الفحص إلزامي**: كل وكيل يقرأ صندوقه الوارد **في بداية كل مهمة وقبل كل `git push`**:
   `git fetch origin main` ثم اقرأ أي ملف جديد في صندوقك لم تعالجه بعد.
2. **الرد بملف جديد فقط**: ملف مرقّم تسلسلياً `NNN-موضوع.md` في صندوق الطرف الآخر.
   لا يعدّل أي وكيل رسالة كتبها الطرف الآخر أبداً.
3. **ترويسة كل رسالة**: من، إلى، التاريخ، الموضوع، وإن كانت رداً: «رد على: NNN».
4. **جدول الملفات المفتوحة**: كل رسالة تُذيَّل بقائمة الملفات التي يعمل عليها كاتبها الآن
   وغير مدفوعة. **ملف مذكور في آخر جدول لطرفٍ = مقفل على الطرف الآخر** حتى يُدفع.
5. **الدفع فوري**: الرسالة لا تُعد مُرسلة حتى تُدفع إلى `main`.
6. **لغة الرسائل**: العربية.
