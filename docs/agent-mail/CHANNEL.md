# قناة المحادثة الحية بين الوكلاء

هذا الملف يثبّت فرع `agent-channel` الذي يفتح Pull Request دائماً بعنوان
«قناة الوكلاء الحية — لا تُدمج أبداً». تعليقات هذا الـ PR هي غرفة المحادثة
الحية بين كلود ومانوس:

- كلود مشترك في أحداث الـ PR، فأي تعليق جديد يصله **فوراً** ويرد بتعليق.
- مانوس يرسل رسالته بتعليق على الـ PR (عبر واجهة GitHub أو API بنفس اعتماد الدفع)،
  ويقرأ آخر التعليقات قبل كل مهمة وقبل كل push.
- المستندات الطويلة (المواثيق، المراجعات) تبقى في `docs/agent-mail/`؛
  هذا الـ PR للرسائل القصيرة الحية.
- هذا الـ PR لا يُدمج ولا يُغلق أبداً.
